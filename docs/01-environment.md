### 重要：Claude Code（クラウド版）でできること・できないこと

| できる | できない |
|---|---|
| C++コード・設定ファイル・ドキュメントの作成 | Unreal Editor の起動・画面確認 |
| サーバー側ロジック（DB・API）の作成とテスト | Windows向けビルド・パッケージ化 |
| Gitでの変更管理 | ブループリントやレベル（.uasset/.umap）の編集 |
| ゲームバランス計算のシミュレーション | 実際のプレイ確認 |

つまり **Unreal Engine 上での最終的なビルドと動作確認は、あなたのPCで行う必要があります。**
Claude が書いたC++コードは「あなたのPCでビルド成功するまで未検証」として扱います。

将来的には、あなたのPCで Claude Code（デスクトップアプリ等）を動かすか、Remote Control でPCのフォルダをこのセッションに接続すれば、Claude が直接ビルドとエラー調査を行えるようになります。

## 2. あなたのPCを確認する手順

`tools/check-pc.ps1` を用意しました。Windows で以下を実行し、出力された `pc-report.txt` の内容を Claude に貼り付けてください。

1. スタートメニューで「PowerShell」と入力して開く
2. このリポジトリを置いたフォルダへ移動（例）：
   ```powershell
   cd C:\Dev\game
   ```
3. 実行：
   ```powershell
   powershell -ExecutionPolicy Bypass -File .\tools\check-pc.ps1
   ```
4. 同じフォルダに `pc-report.txt` が作られます（個人情報は含みませんが、念のため中身を確認してから共有してください）

まだリポジトリをPCに置いていない場合は、`docs/05-setup-guide.md` の手順1〜3を先に行ってください。

## 3. 推奨PCスペック（UE5 オープンワールド＋マルチプレイ開発）

| 項目 | 最低ライン | 推奨 |
|---|---|---|
| OS | Windows 10 64bit | Windows 11 64bit |
| CPU | 6コア | 8コア以上（コンパイル時間に直結） |
| メモリ | 32GB | 64GB（エディタ＋サーバー＋クライアント2つを同時起動するため） |
| GPU | DirectX 12 対応・VRAM 8GB | VRAM 12GB以上（RTX 3060 12GB / 4070 クラス） |
| ストレージ | SSD 空き200GB | NVMe SSD 空き500GB以上（ソースビルド版エンジンは単体で約200〜300GB） |

マルチプレイ検証では「サーバー1＋クライアント2〜3」を同時に動かすため、メモリが最も不足しやすい部分です。

### エンジンのバージョンについて

- 開発開始時点の最新安定版（5.x）を採用し、**途中で安易にバージョンを上げない**。
- 専用サーバー（Dedicated Server）を**パッケージ化**するには、GitHub から入手する**ソースビルド版エンジン**が必要です。ランチャー版ではサーバー単体の書き出しができません。
- ただし第1段階では、ランチャー版エディタの「Play As Client」機能で**専用サーバーの動作をエディタ内でシミュレーション**できるため、ソースビルドは第2〜3段階まで先送りします（容量と手間の節約）。
