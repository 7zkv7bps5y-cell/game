## 4. 整理の提案【追加提案・未承認】

### 4-1. 重複の多い組み合わせは、どちらかに統合する
| 組み合わせ | 提案 |
|---|---|
| セルグラント ↔ 苔王 | セルグラントを通常の大型、苔王をボス級として**役割を分ける**か、どちらかに統合する |
| ドラグネヴァ ↔ 根喰い竜・坑道大百足・掘削土竜 | 地中の大型は1〜2体に絞る |
| クラッグル ↔ ピッカリム | 「鉱物の目印」はどちらか1つに絞る |
| リュミノッカ ↔ 灯茸蜥蜴 | 発光系の小型はどちらか1つに絞る |
| ハルムシェード ↔ 擬樹獣 | ハルムシェード（観察・小型）と擬樹獣（戦闘・中型）で役割を分ければ両立可能 |

### 4-2. 独自性が高く、既存の仕組みとよくつながる候補
- **グレイヴァル**：重複が少なく、刃の向きで変わる戦闘が独自。痕跡で追跡できる
- **フェルナク**：新しい環境（湿地）を加え、農家の地下水発見とつながる
- **バルドリス**：埋まった採集物を露出させる、採集とつながる役割

### 4-3. A-3 の生物の数
A-3 には、採用済み11種（モンスター8＋環境生物3）、検討中の候補が24種（Claude 案6＋ボス候補8＋今回10）あります。製品版の A-3 に何種類くらい入れるか、目安を決めておくと選びやすくなります。
