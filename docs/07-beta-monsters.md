## 1. 設計方針 【確定（2026-11-24）】

| 方針 | 内容 |
|---|---|
| 大きさ | 大型モンスターは**モンスターハンター級の大きさ**にする |
| 雰囲気 | **ファンタジー寄り**。ただ大きいだけの動物ではなく、**異世界感**のあるデザインや能力にする（例：牙の形が独特、おならをジェット噴射して突進する など） |
| 出自 | A-3 に出るモンスターは、接続によって入り込んだ**B世界の生物** |
| 環境生物 | 接続の影響で変化した**A世界の動物**は、モンスターとは区別して**「環境生物」**として扱う（Claude の追加提案をオーナーが採用） |
| 数の目安 | 大型2〜3体、中型1〜2体、小型3体程度。たたき台以外の追加も可 |
| ボス級個体 | 大型との戦いで苦戦や達成感が足りない場合は、**ボス級個体**を設ける |
| 大事にすること | **難しさ**、**達成感**、そして**「それで何ができるのか」というワクワク**（倒して得た素材で何が作れる・何ができるようになるか） |
| 参考の仕方 | モンスターハンター系のドラゴンのような存在は良い。可愛らしすぎるデザインは避ける。神話・伝承・未確認生物などを**モチーフ**にして作り替えるのは可（例：ネッシー＝首長竜、龍） |

### 著作権上の注意（Claude からの補足）
- 神話・伝承・未確認生物（ネッシー、ワイバーン、ジャッカロープ、龍など）は誰でも使える題材なので、モチーフにして問題ありません。
- 一方で、**既存ゲームのモンスターそのもののデザイン・名前・特徴的な組み合わせ**を真似ることは避けます。「既存の作品が参考にした元ネタ（神話など）まで戻って、そこから独自に作る」方針にします。

## 2. たたき台：大型モンスター 【追加提案・未承認】

### M-01 ガルドボア（仮）— 噴射突進の大猪
| 項目 | 内容 |
|---|---|
| 大きさ | 大型（モンハン級） |
| 異世界感 | 牙がらせん状に伸び、途中で枝分かれして角のようになる。腸に可燃性のガスをため、**おならをジェット噴射して爆発的に突進**する。噴射の前には腹が膨らむ（攻撃の予兆） |
| モチーフ | 猪 ＋ 北欧神話の黄金の猪のような「神獣の猪」 |
| 戦いの特徴 | 噴射突進の回避が中心。ガス袋を壊すと突進が弱まるが、ガス袋の素材は取れなくなる |
| 主な素材 | 腿肉（料理人）、らせん大牙（鍛冶師）、牙の欠片、**噴射袋**（錬金術師・爆発物の材料）、鮮血（錬金術師） |
| 獲得方式の差 | 剥ぎ取り：牙の欠片・剛毛／部分搬送：**完全ならせん大牙**（牙が壊れていない場合のみ）・腿肉の塊／全体搬送：**無傷の噴射袋**（死体ごと運ばないと破れる）・骨格一式 |
| 劣化 | 腿肉＝速い、噴射袋＝非常に速い（時間が経つとガスが抜ける）、牙・骨＝劣化しない |

### M-02 鉱背竜（仮）— 鉱石を食べる歩く鉱山 ⭐オーナー好評
| 項目 | 内容 |
|---|---|
| 大きさ | 大型（モンハン級。最大級） |
| 異世界感 | 採掘地の鉱石を食べ、背中に**結晶化した鉱石の塔**が何本も生えている。怒ると体内で鉱石を溶かし、**溶けた鉱滓を吐く** |
| モチーフ | 陸亀・鎧竜 ＋ 伝承の「島と間違えられるほど巨大な亀」 |
| 戦いの特徴 | 硬い背中は攻撃が通りにくい。腹や脚を狙う。背中の結晶を壊すと鉱石が飛び散る |
| 主な素材 | 鉱殻（鍛冶師）、結晶塔の欠片（鍛冶師）、**炉心石**（鍛冶師・錬金術師） |
| 獲得方式の差 | 剥ぎ取り：鉱殻の欠片／部分搬送：**完全な結晶塔**（壊していない場合のみ）／全体搬送：**炉心石**（体内の奥にあり、街での解体が必要） |
| 劣化 | ほぼ劣化しない（鉱物）。そのかわり**非常に重い**ので、搬送に大型設備や人数が必要 |

### M-03 霧爪（仮）— 霧に溶ける毒の大猫
| 項目 | 内容 |
|---|---|
| 大きさ | 中〜大型 |
| 異世界感 | 肩の器官から**毒の霧**を出し、霧の中で体が半透明になって姿を消す。尾の先で霧を操る |
| モチーフ | 大型のネコ科 ＋ 伝承の「霧や闇に潜む獣」 |
| 戦いの特徴 | 霧の中での索敵がカギ。霧を晴らす道具（錬金術師の製品）があると有利になる |
| 主な素材 | **毒腺**（錬金術師）、霧膜（錬金術師）、爪（鍛冶師）、毛皮 |
| 獲得方式の差 | 剥ぎ取り：爪・毛皮／部分搬送：**霧膜**（肩の器官ごと切り出す）／全体搬送：**新鮮な毒腺**（数十分で傷むため、冷却設備付きの全体搬送が必要） |
| 劣化 | 毒腺・霧膜＝非常に速い |

### M-04 森翼竜（仮）— 樹冠の飛竜（ボス級候補） ⭐オーナー好評
| 項目 | 内容 |
|---|---|
| 大きさ | 大型 |
| 異世界感 | 森の樹冠に巣を作る飛竜。翼の膜が**葉のように光合成**し、日中は力が強く、夜は弱る（時間で状態が変わる例） |
| モチーフ | 西洋紋章のワイバーン（伝承の飛竜） |
| 位置づけ | ベータの大型の中で最も手強い相手、または**ボス級個体**の候補 |
| 主な素材 | 翼膜、飛竜の鱗、**光合成器官**（錬金術師） |
| 獲得方式の差 | 剥ぎ取り：鱗／部分搬送：**完全な翼膜**（翼を壊していない場合のみ）／全体搬送：骨格一式・光合成器官 |

## 4. 環境生物（A世界の動物が変化したもの）【方針は確定。個々は追加提案・未承認】

モンスターとは区別します。主に森の生態系を表し、基本的な素材の供給源になります。

| 仮名 | 元の動物 | 変化 | 役割 |
|---|---|---|---|
| 晶角鹿 | 鹿 | 角に結晶が生え始めている | 肉・皮の基本素材。接続の影響を感じさせる |
| 大甲虫 | 甲虫 | 異常に大きくなった | 甲殻（序盤の防具素材） |
| 変異鴉 | カラス | モンスターの死体に集まる | **死体を放置すると集まって素材を減らす**（劣化と組み合わせた要素の候補） |

## 5. ボス級個体の考え方 【方針は確定。中身は追加提案・未承認】
- 通常の大型モンスターより強い**特別な個体**（例：古傷のガルドボア、結晶塔が異常に育った鉱背竜）。
- **専用の素材**を持ち、その素材でしか作れない装備や特殊効果がある →「それで何ができるのか」のワクワク。
- 出現の条件（時間、遠征許可の長さ、依頼の進行など）は今後決める。

## 6. 素材と職業の対応（たたき台から見た需要のバランス）

| 職業 | A-3 で主に使う素材 |
|---|---|
| 料理人 | 腿肉、狼肉、兎肉、蜜、蟹の身、鹿肉 |
| 鍛冶師 | らせん大牙、骨、鉱殻、結晶塔、炉心石、爪、鱗、殻の鉱石＋採掘した鉱石 |
| 錬金術師 | 鮮血、噴射袋、毒腺、霧膜、光合成器官、発光器、毒針＋薬草・キノコ |
| 農家 | 骨粉（肥料）、採取した薬草・キノコの栽培 |
| 商人 | 琥珀の巣の珍品、ボス級の素材など希少品の流通 |

**5つの職業すべてに A-3 での需要があり、3つの獲得方式それぞれに選ぶ理由がある**ように配置しています。
