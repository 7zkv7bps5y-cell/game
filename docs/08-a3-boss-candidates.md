## 2. 各候補の詳細設計

### BC-01 ヴェルザーン／縫界獣

| 項目 | 内容 |
|---|---|
| 外見・特徴 | 【指示書】枝のような骨格と鉱物が融合した、左右非対称の姿。空間や距離感に干渉する。【追加提案】体の一部が「ずれて」見え、骨の継ぎ目が光る線（縫い目）になっている |
| 生息環境 | 【追加提案】森と坑道が接する断層帯（A-3 の最奥） |
| 生態系での役割 | 【追加提案】地形の裂け目を開いたり閉じたりし、他の生物の移動ルートを変える |
| 他モンスターとの関係 | 【追加提案】鉱背竜の移動ルートが変わる。霧爪が裂け目を通り道に使う |
| 遭遇条件 | 【追加提案】長い遠征許可で最奥に到達したとき。予兆として、方位や距離の表示が狂う |
| 戦闘難易度 | 【追加提案】★5（A-3 で最も難しい） |
| 攻撃パターン | 【追加提案】枝骨の突き刺し／空間の縫い目を使って一瞬で間合いを詰める／離れたプレイヤーを引き寄せる |
| 独自ギミック | 【指示書】戦闘中の位置認識や移動判断に影響。【追加提案】一定範囲で「見た目の距離」と「実際の距離」がずれる。光る縫い目を壊すと解除 |
| 弱点部位 | 【追加提案】体の継ぎ目にある「縫い目の核」 |
| 部位破壊 | 【追加提案】枝骨（折ると攻撃範囲が縮む）、鉱物の瘤 |
| 剥ぎ取り限定素材 | 【追加提案】枝骨の欠片 |
| 部分搬送限定素材 | 【追加提案】完全な枝骨（折らずに倒した場合のみ） |
| 全体搬送限定素材 | 【追加提案】**縫界核**：死後もしばらく空間の歪みを出し続けるため、運ぶこと自体が難しい |
| 加工先・用途 | 【指示書】探索技術、空間関連装備、輸送技術。【追加提案】正確な方位・距離を測る探索道具、地図関連の道具 |
| 職業との関連 | 【追加提案】錬金術師（縫界核の加工）、鍛冶師（枝骨の武器）、商人（希少品の流通） |
| 経済への影響 | 【追加提案】非常に希少。月例オークション向けの最高級素材 |
| 注意点 | **「輸送技術」への活用は、決定済みの原則と衝突する可能性があります**（3章の矛盾1）。距離感の干渉は、マルチプレイでの同期と画面表現の負担が大きい |

|---|---|

| 生態系での役割 | 【追加提案】地熱を吸い上げて体にため、周りの鉱石を変質させる（質の良い鉱石ができる） |
| 他モンスターとの関係 | 【追加提案】鉱背竜と縄張りを争う。鉱背竜は鉱石を「食べる」、灰冠巨獣は熱を「ためる」と役割を分ける |
| 遭遇条件 | 【追加提案】坑道の気温が上がることが予兆 |
| 戦闘難易度 | 【追加提案】★4 |
| 攻撃パターン | 【追加提案】ためた熱を全方位に放出する爆発／灰を降らせて視界を悪くする／岩の殻での体当たり |
| 独自ギミック | 【指示書】周囲の地形や温度が変化し、熱の蓄積と放出を軸に戦う。【追加提案】熱がたまると殻が赤くなり、攻撃が通るが危険。放出後は冷えて硬くなる。**周囲の温度が上がると、その場の素材の劣化が早まる**（鮮度の仕組みと連動） |

| 全体搬送限定素材 | 【追加提案】**蓄熱炉心**：熱を保つ器官。冷めると価値が下がる（この素材にとっての「劣化」は冷えること） |
| 加工先・用途 | 【指示書】生産設備、熱利用技術、装備開発。【追加提案】炉などの加熱設備（借家に置く職業専用設備）、耐熱防具 |

## 3. 既存仕様との重複・矛盾（報告）

### 矛盾
| No. | 内容 | 既存の決定 | 対応 |
|---|---|---|---|
| 矛盾1 | 縫界獣の素材を「輸送技術」に使う | 「搬送の大変さを職業の能力で簡単に解決させない」原則（2026-11-24 決定）、商人の積載量アップ案の不採用 | 修正はしていません。空間に関する素材で積載量や移動を楽にすると、部分搬送・全体搬送の価値が崩れる可能性があります。**推奨：用途を「探索・測位」に限る** |
| 矛盾2 | 縫界獣の「空間や境界に干渉する」性質 | 世界の接続は母が企てたもので、物語の中心（`01-world-and-story.md`）。製品版の構想でも X-1 に「境界獣」を置いている | 物語上の問題があるわけではありませんが、A-3 という序盤の地域で「空間の境界」を扱うと、物語の核心に早く触れすぎる可能性があります。物語との関係を決める必要があります |

### 重複
| No. | 内容 |
|---|---|
| 重複1 | **鉱物の要素が集中**しています。5体のうち4体（縫界獣・灰冠巨獣・鏡殻異虫・灰雨繭母）が鉱物を取り込みます。既存の鉱背竜・岩殻蟹も鉱物系です |
| 重複2 | 飛行型の大型：枯鐘竜と森翼竜（製品版の追加候補にも夜梟竜がいます） |
| 重複3 | 灰冠巨獣の「熱をためる」「炉心」は、鉱背竜の「溶けた鉱滓を吐く」「炉心石」と近い |
| 重複4 | 名前の「灰」：灰冠巨獣と灰雨繭母 |

### 4-2. 選び方の提案
