## 4. 討伐後の素材獲得（3方式）

### 4-1. 共通ルール
- 剥ぎ取り・部分搬送・全体搬送の**3方式を採用する**【確定】。
- 3方式の違いは倍率ではなく、**手に入る素材の種類そのもの**【確定】。
- 共通素材（複数の方式で取れる）と、方式専用素材を設定する。各方式に専用素材を1つ以上持たせる【確定】。
- 確率は、モンスター・素材・方式ごとにデータテーブルで設定する。数値は未定【方向性】。
- 全体搬送が常に最も得な選択にはしない【確定】。

### 4-2. 方式ごとの特徴

| | 剥ぎ取り | 部分搬送 | 全体搬送 |
|---|---|---|---|
| 内容 | 現地ですばやく回収 | 必要な部位を選んで持ち帰る | 死体全体を持ち帰る |
| 必要なもの | 大がかりな設備は不要 | 馬車・荷車・車両などの輸送設備 | 大型の輸送設備。複数人の協力が必要な場合あり |
| レア素材の確率 | 低め（0%にはしない） | 剥ぎ取りより高い | 3方式の中で高い |
| 専用素材 | あり | あり | あり（研究価値・追加報酬も検討） |
| リスク・費用 | 劣化を抑えやすい | 輸送時間、設備費、劣化 | 輸送費、時間、劣化、人員 |
| 状態 | 【方向性】 | 【方向性】 | 【方向性】 |

### 4-3. 例：仮モンスター「ガルドボア」（考え方を示す例。最終的な素材表ではない）
- 剥ぎ取り：牙の欠片
- 部分搬送：完全な大牙
- 全体搬送：骨格一式、鮮血

詳細なデータ構造（部位、重量、劣化区分、出現ルール）は `06-materials-and-trade.md` A章にあります【Claude提案・未承認】。

## 7. 生活職業

### 7-1. 共通方針 【方向性】
- 戦闘とは別に生活職業を選ぶ。
- 職業ごとに明確な役割を持たせ、職業の異なるプレイヤー同士が必要になる設計にする。
- **個人に対する能力**と、**パーティーに提供できる能力**を持たせる。
- 職業ギルド・職業専用の施設を設ける。
- 職業ごとの生産物に需要が生まれる経済を作る。
- **メイン職業は1つ。変更はできるが代償がある**【確定】（2026-11-23 決定）。
- **職業はチュートリアルの中で選ぶ**。ストーリーやプレイヤーの行動が始まる前に決まっている【確定】（2026-11-24 決定）。
- **熟練度は、その職業の作業（料理を作る、修理するなど）をすると上がる**【確定】（2026-11-24 決定）。
- **採取・採掘は誰でもできる**【確定】（2026-11-24 決定）。
- **職業変更の代償**：お金がかかる。**生活職のレベル・熟練度が1から**やり直し。**戦闘面（キャラクターレベルなど）には影響しない**【確定】（2026-11-24 決定）（2026-11-24 訂正）。職業で得たアイテムをどう扱うかは未定 → Q-S21

### 7-3. 農家の作物 【確定（2026-11-24）】
- **外に出なくても食料が手に入る**ことが農家の大きなメリット。
- 使い道：料理の食材（料理人）、薬の材料（錬金術師）、将来は荷車を引く動物や家畜の餌（B-2 のモンスター共存の文化と関係）。
- **職業ごとのギルドに卸してお金に変えられる**（職業ギルドは製品を売る場所であると同時に、素材を卸す先でもある）。
- **養蜂**などもできるようにしたい【方向性】。
- **養蜂には琥珀蜂（A-3 のモンスター）を使う**：部分搬送で琥珀蜂の巣を持ち帰り、農家が借家や畑で育てると、蜜や琥珀がとれる【確定】（2026-11-25 決定）。

### 7-4. 生活職の解放の仕組み 【確定（2026-11-24）】
- 解放されるものの種類：職業の基本能力／上位のレシピ／パーティーへの効果／職業専用の設備（借家に置ける）／特殊効果の付与・ボス級素材の加工。
- これらを5段階にまとめるのではなく、**レベルの途中に散りばめて**少しずつ解放していく。

### 7-5. バランスの原則 【確定（2026-11-24）】
- **不採用**：商人がパーティーの荷車の積載量を増やす案（持てる重量の増加をパーティーに広げる案）。
  - 理由：バランスが崩れ、部分搬送・全体搬送の意味がなくなる。商人だけに偏る。
- **原則**：特定の職業だけを強くしない。ある職業に強い効果を足すなら、他の職業にも同じくらいの効果を足す。
- **原則**：搬送の大変さ（積載量・重量の制限）を、職業の能力で簡単に解決できないようにする。
- **原則**：**職業はあくまで「上位版」が手に入るもの**。基礎的な物やある程度の物は、**誰でもクラフト・売買・探索で入手できる**ようにする。職業の専属にしすぎると、ソロプレイヤーが何もできなくなるため、制限が強すぎる設計は避ける【確定】（2026-11-25 決定）。

### 7-6. 職業の追加・共同制作 【確定（2026-11-25）】
- **職業は追加しない**：解体師・大工・調教師の案は不採用。生活職は商人・料理人・鍛冶師・農家・錬金術師の5つ。
- **共同制作**（上位装備に複数職業の工程を必要とする案）は不採用。ただし、**形を変えて近いものを追加する可能性はある**。
