## 4. 討伐後の素材獲得（3方式）

### 4-1. 共通ルール
- 剥ぎ取り・部分搬送・全体搬送の**3方式を採用する**【確定】。
- 3方式の違いは倍率ではなく、**手に入る素材の種類そのもの**【確定】。
- 共通素材（複数の方式で取れる）と、方式専用素材を設定する。各方式に専用素材を1つ以上持たせる【確定】。
- 確率は、モンスター・素材・方式ごとにデータテーブルで設定する。数値は未定【方向性】。
- 全体搬送が常に最も得な選択にはしない【確定】。

### 4-2. 方式ごとの特徴

| | 剥ぎ取り | 部分搬送 | 全体搬送 |
|---|---|---|---|
| 内容 | 現地ですばやく回収 | 必要な部位を選んで持ち帰る | 死体全体を持ち帰る |
| 必要なもの | 大がかりな設備は不要 | 馬車・荷車・車両などの輸送設備 | 大型の輸送設備。複数人の協力が必要な場合あり |
| レア素材の確率 | 低め（0%にはしない） | 剥ぎ取りより高い | 3方式の中で高い |
| 専用素材 | あり | あり | あり（研究価値・追加報酬も検討） |
| リスク・費用 | 劣化を抑えやすい | 輸送時間、設備費、劣化 | 輸送費、時間、劣化、人員 |
| 状態 | 【方向性】 | 【方向性】 | 【方向性】 |

### 4-3. 例：仮モンスター「ガルドボア」（考え方を示す例。最終的な素材表ではない）
- 剥ぎ取り：牙の欠片
- 部分搬送：完全な大牙
- 全体搬送：骨格一式、鮮血

詳細なデータ構造（部位、重量、劣化区分、出現ルール）は `06-materials-and-trade.md` A章にあります【Claude提案・未承認】。

### 4-4. 搬送とマルチプレイ 【検討中】
- 複数人で荷車を押す、馬車や車両を操作する、搬送中の護衛
- 搬送設備の所有・製作・耐久値
- 搬送中のモンスターや環境による危険
- ソロプレイヤーが全体搬送を行う手段 → Q-S14
- 技術案：荷車は物理シミュレーションを簡略化して、同期の不具合を避ける（`03-difficulty-and-sourcing.md`）【Claude提案・未承認】

## 7. 生活職業

### 7-1. 共通方針 【方向性】
- 戦闘とは別に生活職業を選ぶ。
- 職業ごとに明確な役割を持たせ、職業の異なるプレイヤー同士が必要になる設計にする。
- **個人に対する能力**と、**パーティーに提供できる能力**を持たせる。
- 職業ギルド・職業専用の施設を設ける。
- 職業ごとの生産物に需要が生まれる経済を作る。
- 職業の変更や兼業ができるか → Q-S13

### 7-2. 職業一覧

| 職業 | 個人の能力（構想） | パーティー・他者への貢献（構想） | 主な需要素材 | 状態 |
|---|---|---|---|---|
| 商人 | 所持・運搬できる重量の増加、売買・取引での優位 | 流通、希少品の確保 | 全般・希少品 | 【方向性】 |
| 料理人 | 料理の制作、食品の品質向上、食材の加工・販売 | **パーティーへの食事効果** | 肉・食材・特殊食材（鮮度を重視） | 【方向性】 |
| 鍛冶師（当初の名称は「鍛冶職人」） | 採掘関連、武器・防具の制作、修理・強化、耐久の管理 | **パーティーメンバーの装備修理** | 鉱石・骨・牙・角・金属（品質・形状を重視） | 【方向性】 |
| 農家 | 農業、土壌・環境の情報、地下水の発見、収穫場所の把握、農業用具に関係する移動・作業 | 環境情報の共有（詳細未定） | 肥料・農業資材 | 【方向性】 |
| 錬金術師 | 特殊素材の加工、器官や血液の利用、薬品・特殊アイテムの制作 | 未定 | 血液・器官・特殊素材（鮮度を重視） | 【方向性】（正式採用の方向で検討）→ Q-S11 |
| 飲食店経営者 | 料理人の発展形とする案。料理人の能力に加え、店舗・従業員・仕入れ・販売・経営 | 未定 | 料理人と同じ＋仕入れ | 【検討中】（案を推奨中）→ Q-S12 |

- 料理人と飲食店経営者は、**制作の能力と経営の能力を分けて**設計する【方向性】。
- 職業名の表記（「鍛冶職人」と「鍛冶師」）は統一が必要 → Q-S12 に含めます。
