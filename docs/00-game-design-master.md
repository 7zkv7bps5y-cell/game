## 1. ゲームの基本コンセプト

| 項目 | 内容 | 状態 |
|---|---|---|
| ジャンル | マルチプレイ前提のオープンワールド型サバイバル・アクションRPG | 【確定】 |
| 中心となる体験 | 狩猟だけでなく、素材の回収・加工・流通・生活・職業を通じて**プレイヤー同士が互いに必要とされる世界** | 【確定】 |
| 参考要素 | モンスターハンター（狩猟・戦闘・キャラクリ）／Terraria（装備の特殊効果・ビルドの多様性）／Escape from Tarkov（物資の価値・取引・持ち帰りのリスク）／サバイバルゲーム（採取・加工・生活・拠点・探索）。**再現ではなく独自の体験を作る** | 【確定】 |
| マルチプレイ | 前提。ソロでも遊べる余地を残しつつ、複数人で新しい価値が生まれる設計 | 【確定】 |
| 視点 | 一人称と三人称の2択で切り替える | 【確定】（2026-11-23 決定） |
| 対象機種 | 初期はPC。将来的にコンソールを検討 | 【方向性】 |
| エンジン | Unreal Engine 5（C++とBlueprintを併用） | 【方向性】（候補） |
| アセット | 自作・無料ツール・UE標準機能を優先。購入は必須にせず、購入時は事前承認 | 【確定】 |
| 対人戦（PvP） | 当面は入れない。将来的には可能性あり | 【確定】（当面なし）（2026-11-23 決定）。将来は【検討中】 |

### このゲームを支える5本の柱（構想の要約）
1. **狩る**：武器・特殊効果・部位破壊のある戦闘
2. **持ち帰る**：剥ぎ取り／部分搬送／全体搬送の選択と、鮮度・輸送のリスク
3. **作る**：加工・クラフト・料理・錬金によって素材に価値を付ける
4. **暮らす**：住宅・家賃・遠征許可・職業による生活
5. **関わる**：取引・依頼・ギルド・派閥・ストーリー分岐

## 5. ゲームシステム（詳細：`02-game-systems.md`）

| システム | 要約 | 状態 |
|---|---|---|
| キャラクタークリエイト | 目標はモンスターハンターワイルズ級の自由度。実装可能な範囲と費用は調査中 | 【方向性】 |
| 戦闘 | 近接・遠距離、回避・防御、武器固有アクション、特殊効果、モンスターAI、部位破壊 | 【確定】（要素） |
| 戦闘スタイル | 生活職業とは別に、装備の組み合わせなどで構築する | 【方向性】 |
| 戦闘の成長 | 固定の戦闘クラスはなし。キャラクターレベル＋武器ごとの熟練度（生活職業の熟練度は別） | 【確定】（2026-11-23 決定） |
| 素材獲得の3方式 | 剥ぎ取り・部分搬送・全体搬送。**手に入る素材の種類そのもの**が異なる。各方式に専用素材を1つ以上 | 【確定】 |
| レア素材の確率 | 剥ぎ取り＜部分搬送＜全体搬送の順で高くする（剥ぎ取りも0%にはしない）。数値はデータテーブルで管理し、未確定 | 【方向性】 |
| 全体搬送 | 常に最も得な選択にはしない | 【確定】 |
| 劣化 | 死体・部位の鮮度と、取得素材の鮮度を分けて管理する | 【確定】 |
| 劣化速度 | 素材ごとに設定。5段階に分ける案 | 【方向性】／【検討中】 |
| ログアウト中の劣化 | 現実時間で常に進む | 【確定】（2026-11-23 決定） |
| 保存庫の性能 | 劣化を**遅くするだけ**（止めはしない）。容量・料金・性能の数値は未定 | 【確定】（2026-11-23 決定） |
| 保存場所 | ①**ギルドの保存庫**（有料）：部分搬送・全体搬送で持ち帰った部位や死体だけを入れられる。血液・肉などインベントリに入る素材は入れられない。②インベントリに入る素材は**宿や借家**に保管する。これを宿や家を借りる理由にする | 【確定】（2026-11-23 決定） |
| 鮮度の計算方法 | 毎秒更新せず、参照するときに計算する | 【方向性】 |
| クラフト・加工 | 素材の品質・職業・設備が結果に影響。修理・強化・加工・特殊効果 | 【方向性】 |
| 生活職業 | 商人・料理人・鍛冶師・農家・**錬金術師**（錬金術師は正式採用（2026-11-23 決定））。飲食店経営者は料理人の発展形とする案を推奨 | 【方向性】 |
| 職業の数・変更 | メイン職業は1つ。変更はできるが代償（熟練度の低下など）がある | 【確定】（2026-11-23 決定） |
| ギルド | 共通ギルドと職業ギルド・専門施設 | 【方向性】 |
| 住宅 | 賃貸・家賃・家具・保管庫。滞納すると段階的に設備が使えなくなり、最終的に住居を失う。救済策を検討。**ベータ版に含める** | 【検討中】（ベータに含めることは【確定】（2026-11-23 決定）） |
| 遠征許可 | 時間制限付き。期限を過ぎると所持品を失い、病院で目覚める案。**ベータ版に含める** | 【検討中】（ベータに含めることは【確定】（2026-11-23 決定）） |

| 個人依頼の判定 | 支払い条件はサーバーが自動で判定できるものを基本とする | 【方向性】 |
| NPC経済 | 人口が少ない時期は、NPCが最低限の買取・販売・需要を担う。ただしプレイヤー取引の余地を残す | 【方向性】 |

| 権威 | 通貨・所有権・出自・取引結果はサーバー側で管理する | 【方向性】 |
