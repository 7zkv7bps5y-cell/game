## 1. 経済の基本方針

| 方針 | 状態 |
|---|---|
| 狩猟者だけが儲かる構造にしない。加工・調理・製造・販売する人にも利益が生まれるようにする | 【確定】 |
| 素材の採取 → 加工 → 製作 → 流通までを、プレイヤー同士のつながりにする | 【確定】 |
| 供給量・需要量・劣化・加工コスト・輸送コストを経済に反映させる | 【方向性】 |
| 通貨・所有権・素材の出自・取引の結果はサーバーで管理する | 【方向性】 |
| ストーリーを大きく壊す装備・アイテムの流通を制限する。装備にレベルや条件による制限を設ける | 【方向性】（基準は未定 → Q-E5） |

## 2. 需要：誰が何を必要とするか

| 需要者 | 主な素材 | 何を重視するか | 状態 |
|---|---|---|---|
| 料理人・飲食店 | 肉、食材、特殊食材 | 鮮度 | 【方向性】 |
| 鍛冶師 | 鉱石、骨、牙、角、金属 | 品質・形状（部位が壊れていないか） | 【方向性】 |
| 錬金術師 | 血液、器官、特殊素材、毒 | 鮮度（特に短時間） | 【方向性】 |
| 農家 | 肥料、農業資材 | 未定 | 【方向性】 |
| 商人 | 全般、希少品 | 価格差・流通。ギルドの費用割引、ブラックマーケットでの強み（案） | 【方向性】 |
| NPC | ギルドの買取・販売・最低限の需要 | - | 【方向性】 |

### 劣化した素材の再利用 【確定】
- 素材ごとに再利用の方法を定める。**すべてを一律に肥料へ変換しない。**
- `06-materials-and-trade.md` D章では、農家を「劣化した素材や余った素材の受け皿」と書いており、一律変換と読める表現になっている → **矛盾（表現）** → Q-E3

### 需要が生まれる理由（各システムからの整理）
```
戦闘で強くなりたい ─→ 料理（食事効果）・薬（錬金）・装備（鍛冶）が必要
                      └→ 料理人・錬金術師・鍛冶師に素材の需要が生まれる
鮮度が落ちる      ─→ 早く運ぶ・冷やす・加工する人に価値が生まれる
運ぶのが大変      ─→ 荷車（クラフト）・護衛・協力の需要
家賃・許可証・修理 ─→ 継続的にお金を稼ぐ必要（お金の出口でもある）
```

## 3. 流通経路（6つ）【検討中】

| 経路 | 内容 | 現在の構想 | 主なリスク・制限 |
|---|---|---|---|
| ① ギルド卸売 | 職業や素材の流通を支える基本の経路 | 共通ギルドの「素材の卸売」窓口。職業ギルドとの関係は未定 | 少ない |
| ② 直接取引 | プレイヤー同士が売買・譲渡する | 双方が確認して同時に交換する | 取引画面の外の約束は保証しない（`06` の案） |
| ③ ブラックマーケット | 一般の市場で扱えない特殊素材・禁制品 | 運営勢力・ストーリーとの関係は未定 → Q-E1 | 摘発・没収・勢力評価の低下（案） |
| ④ 月例オークション | 希少素材・高価値アイテム | 入札金の預かり、落札・不成立時の決済、保管中の劣化対策 | 開催周期の基準は未定 → Q-E7 |
| ⑤ 個人依頼・個人契約 | 特定素材を他のプレイヤーに依頼する | 報酬をシステムが預かり、条件を満たしたら支払う | 4章を参照 |
| ⑥ フリーマーケット | 当初仕様の「市場」にあたる。Tarkov から着想 | 3-1 を参照 | 出品できない物がある |

- 経路ごとに違うのは、手数料・決済のタイミング・リスク・出品制限など【検討中】。
- 当初の仕様書の「**市場**」は⑥フリーマーケットとして扱う【確定】（2026-11-23 決定）。
- 「**職業別販売カウンター**」は**職業ギルドに置き、その職業の製品を売る場所**にする。NPCの客も買いに来る【確定】（2026-11-24 決定）。

### 3-1. フリーマーケット【確定（2026-11-23）。詳細は未定】
| 項目 | 決定内容 | 未定の点 |
|---|---|---|
| 着想 | Escape from Tarkov のフリーマーケット | - |
| どこで買えるか | **どこからでも**購入できる | - |
| 受け取り | **配送業者**が届ける。**配送中は劣化しない**。配送時間で他の経路と差を付けることはしない（時間関係は現状維持）（2026-11-24 決定） | 配送料金 → Q-E8 |
| 出品できる物 | 素材は出品できる。ただし**出品できない物もある**。製品（装備・料理・薬）も含め、**アイテムが決まり始めたら表で1つずつ出品可否を設定する**（2026-11-24 決定） | 出品可否の表（アイテム設計時に作成） |
| 売り方 | 売り手が値段を決めて並べる（売り注文のみ） | 手数料・利用条件 → Q-E12 |
| 商人との関係 | 商人はフリーマーケットに**関与しない** | - |

**経路ごとの強み（オーナーの考え方。2026-11-24）**：直接取引・個人依頼は、金額が決まっていて、達成すれば確実にお金がもらえる（売る側は必ず売れる）。依頼主は手に入れられる確率が高い。この**確実性**が、フリーマーケットとの違いになる。今後メリット・デメリットを追加することはありうる。

- 手数料などの数値（`06` C-2 の5〜30%など）は仮 → Q-E4

## 4. 個人依頼・個人契約

### 4-1. 設定できる条件 【方向性】
対象モンスター／必要素材／必要数量／獲得方式／品質／鮮度／納品期限／報酬／納品場所／公開・非公開（公開範囲）

依頼の例：
- 飲食店が、特定モンスターの肉を依頼する
- 鍛冶師が、特定の骨や鉱石を依頼する
- 錬金術師が、特殊器官や鮮度の高い血液を依頼する

### 4-2. 支払いの仕組み
| 項目 | 内容 | 状態 |
|---|---|---|
| 報酬の預かり | 依頼を出した時点で、システムが報酬を預かる | 【検討中】 |
| 支払い条件 | サーバーが自動で判定できるものを基本とする | 【方向性】 |
| 出自の記録 | 素材に「どのモンスターから・どの方式で・いつ取得したか」を持たせる | 【方向性】 |
| 例外処理 | 取り消し、辞退、期限切れ、分納、不正な資金移動への対策 | 設計対象（`06` E章に案あり）【Claude提案・未承認】 |

## 5. 所有権・通貨台帳（すべての経路の土台）【検討中：設計案】

`06-materials-and-trade.md` C-1 の案を要約します。

| 要素 | 内容 |
|---|---|
| アイテムの状態 | 所持中／出品中（ロック）／預かり中／搬送中／消費済み |
| 通貨 | すべての増減を台帳に記録する（誰から誰へ・理由・取引ID）。所持金を直接書き換えない |
| 確定の手順 | 検証 → データベースで一括確定 → 結果を通知。失敗したらすべて取り消す |
| 二重処理の防止 | 同じ要求が2回届いても1回だけ処理する |
| 素材の単位 | 鮮度・出自が違う素材は混ぜず、「ロット」で管理する |

この土台は取引の段階まで使いませんが、**アイテムのデータの形（出自・鮮度・所有者）は最初のプロトタイプから決めておく必要があります**（`06-system-dependencies.md` を参照）。

## 6. NPCとプレイヤー経済 【方向性】

- ただし、NPCがすべてを代わりに行うのではなく、プレイヤー同士の取引が成り立つ余地を残す。
- NPCの比重をどう下げていくかは【未定】。

## 9. 通貨 【確定（2026-11-24）。一部未定】

### 9-1. 決定内容
| 項目 | 内容 |
|---|---|
| 目的 | **インフレを抑えること** |
| 種類 | **旧貨幣＝A世界のお金**、**新貨幣＝B世界のお金** |
| 街での支払い | A-1（生存者の街）の宿・家賃などは**旧貨幣**。B-1（B世界の街）では**新貨幣** |
| フリーマーケット・個人依頼 | どちらの通貨で取引するかは、**出品者・依頼主が設定**する |
| 入手方法の違い | **旧貨幣は探索でのドロップでも手に入る**（A世界の廃墟の街 A-2 などがあるため）。これが新貨幣との明確な違い |
| 両替：旧貨幣 → 新貨幣 | **闇商人（NPC。ブラックマーケットを担う）** が行う。理由：他世界のアイテムを好む少数派の買い手に売るため |
| 両替：新貨幣 → 旧貨幣 | **生存者派閥**が行う。理由：B世界とやり取りするために新貨幣が必要なため |

※ 回答の「インフラを抑える」は「インフレを抑える」、「進化兵が必要」は「新貨幣が必要」と解釈して記録しています（オーナーに確認中）。

### 9-2. 以前のオーナー案で、まだ詳細が決まっていないもの
- ブラックマーケットで使うお金は**ダーティーマネー**になり、普通の売買に使うには**資金洗浄**が必要 → 洗浄の方法などは Q-E13

### 9-3. 通貨の流れ（整理）
```
            探索ドロップ（A-2 廃墟など）
                    │
                    ▼
  A-1の宿・家賃 ◀── 旧貨幣 ──(闇商人NPC)──▶ 新貨幣 ──▶ B-1の支払い
                    ▲                          │
                    └────(生存者派閥)◀─────────┘
  フリマ・個人依頼：出品者・依頼主がどちらの通貨かを設定
```

### Claude の見立て（参考）
| 観点 | 内容 |
|---|---|
| 世界観との相性 | 「接続後から始まる」設定と合う。接続を境に通貨が切り替わった、などの説明がしやすい |
| 商人との相性 | 両替や資金洗浄を商人の強みにすれば、「商人はブラックマーケットで力を発揮する」という方向性と直接つながる |
| 不正対策 | ダーティーマネーをフリーマーケットや家賃に直接使えなくすれば、不正に得たお金の流れを追いやすい |
| 注意点 | 通貨が3種類になると、初心者には分かりにくい。画面での見せ方と、最初はどれか1つしか触れない導線が必要 |
| 技術面 | 通貨台帳は最初から「通貨の種類」を持つ形で作れば対応できる（作業量は小さい） |
